# 混合还原机制

## 核心判断

最终 HTML 的目标是高保真可演示，不是把所有东西都代码化。

优先级：

1. 视觉效果高保真；
2. 文字和数据准确；
3. 演示稳定；
4. 关键内容可编辑；
5. 代码结构清晰。

## 元素类型

`html-text`：标题、正文、数字、单位、注释、表格文字、图表标签等权威文字。

`chart`：柱状图、折线图、面积图、环形图、矩阵、时间序列等需要数据准确的图表。

`svg-css`：简单线条、箭头、边框、色块、分割线、基础几何和普通图标。

`raster`：照片、透明产品图、人物、门店、设施、品牌物料、截图等独立图片。

`visual-module`：复杂插画、地图底图、品牌纹理、场景组合、复杂机制图、无法无损拆开的设计组。

`stage3-reference`：阶段三生成的整页高清视觉稿，例如 `stage3_production/slides/slide_01.png`。它只能作为视觉对比靶子和人工确认依据，不是阶段四运行时素材。

`micro-visual`：微型但影响设计感和信息关系的元素，例如信息型图标、虚线、引线、端点圆点、箭头、节点锚点。它们不是可随意删除的装饰。

`geometry-topology`：关系图的整体几何约束，例如金字塔外轮廓、飞轮闭合方向、漏斗中心轴、矩阵网格和地图点位关系。

## 决策规则

优先使用真 HTML 承载权威文字和数据。

如果视觉元素拆开后仍能保持质感和位置，可以拆分。

如果拆开会造成质感下降、关系错位、光影丢失、角色变形、纹理消失或图表语言改变，必须作为图片模块保留。

不要用 CSS 重画品牌角色、产品图、复杂场景、地图纹理或强风格插画。

不要用简化图标替代已确认的品牌、产品、地图、场景和复杂机制模块。

不要用汉字、emoji、标点、百分号、首字母或普通文本替代阶段三确认的信息型图标。

不要省略连接线、虚线、端点和节点锚点；它们通常承担信息绑定和视觉节奏作用。

金字塔、飞轮、漏斗、循环图等关系图必须保持整体几何拓扑。若用代码重建会导致角度不统一、闭合关系错误或节点丢失，应作为局部视觉模块嵌入，而不是简化成近似形状。

## 阶段三与阶段四边界

阶段三负责决定每个元素如何还原，并产出可用素材。

阶段四只能执行阶段三策略。如果发现素材缺失或策略不可行，应回到阶段三补素材或调整拆分，不得在阶段四现场简化设计。

阶段三整页高清视觉稿不是素材库。阶段四不得把 `slide_01.png` 到 `slide_NN.png` 作为整页 `<img>`、整页背景图或主要视觉模块嵌入 HTML，除非用户在当前阶段明确授权 `full-slide-raster`。

允许图片化的是局部生产素材：照片、产品图、地图底图、品牌角色、纹理、复杂插画、复杂机制图或局部场景组。局部素材应放在 `assets/production/`，而不是直接引用阶段三整页视觉稿。

## full-slide-raster

整页图片化不是默认方案。只有当用户明确表示像素保真优先且接受页面不可编辑时，才允许整页作为图片嵌入。即便如此，也应尽量叠加真实 HTML 文本用于清晰显示或可访问性，除非会破坏视觉。

如果用户没有明确授权，以下做法都属于 P0 失败：

- 用阶段三整页视觉稿作为页面可见主体；
- 用整页图片承载绝大部分可见文字和数据；
- 只叠加不可见或近乎透明的“语义文字层”来声称文字是真 HTML；
- 把复杂页面整体截成一张图，而没有拆出可见标题、正文、数字和关键图表。

## 可见 HTML 文字原则

标题、正文、数字、单位、注释、表格文字和图表标签等权威内容必须以普通观众可见的 HTML 文字显示。

不得使用以下方式把 HTML 文字藏起来：

- `opacity` 低于 0.85；
- `color` 或 `text-shadow` 的 alpha 低于 0.85；
- `visibility:hidden`、`display:none`、`aria-only`、离屏定位、零字号；
- 文字层被整页图片覆盖，导致视觉上读到的是图片里的文字。

可访问性语义层可以作为补充，但不能替代可见 HTML 文字。
